# inbox

Drag photos in here from Photos, the Finder, anywhere. The next run of
`make photos` (or the nightly `com.mantel.photos` agent) uploads them to the
frame and moves them to `inbox/sent/`.

This is the path that needs no permissions: use it if the Photos album export
is not working, or for a one-off photo that does not belong in the album.

Everything here except this file is git-ignored.
