# Fonts

`nunito-latin-variable.woff2` — Nunito, latin subset, variable weight 200–1000.
Downloaded once from Google Fonts and committed here: the iPad may be offline
for minutes, and nothing in this app is allowed to reach a CDN.

One variable file rather than three static cuts: it covers 400, 700 and 900
(and everything between) in 39 KB, which is smaller than any two static weights
would have been.

take the `latin` block from:
